# GitHub and Streamlit deployment

1. This repository is the GitHub destination for the BITS AIML Machine Learning Assignment 2.
2. The Streamlit entry point is `app.py`.
3. Install dependencies with `pip install -r requirements.txt`.
4. Run `python train_models.py` to create the saved pipelines and metrics.
5. Run locally with `streamlit run app.py`.
6. For Streamlit Community Cloud, connect this repository and select `app.py` as the main file.
7. Add the deployed app URL and a genuine BITS Virtual Lab screenshot to the final PDF after completing those steps.
